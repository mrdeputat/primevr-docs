# Политика конфиденциальности бота PrimeVR

**Дата вступления в силу: 03.11.2026**

## 1. Общие положения
PrimeVR (далее — «Бот») обрабатывает минимальный объём данных, необходимый для работы функций. Бот не продаёт, не передаёт третьим лицам и не использует данные для рекламы.

## 2. Какие данные обрабатываются
- **ID пользователей Discord** — для модерации: муты, предупреждения, баны, аудит действий, владение приватными комнатами.
- **Никнеймы/отображаемые имена** — для названия приватных комнат и упоминаний.
- **Содержимое сообщений** — обрабатывается автоматически (автомод: запрещённые слова, ссылки, инвайты, капс, спам) и **не сохраняется** в базе; сохраняются только результат проверки (запись в аудите) и причина.
- **Голосовая активность** — факт входа/выхода в голосовые каналы (для приватных комнат). Разговоры **не записываются**.
- **Данные входа в веб-панель** — Discord OAuth2: имя пользователя, ID и роли на сервере (для проверки прав). Пароли не собираются: вход только через Discord.
- **Аудит действий** — кто, что и когда сделал командами Бота.

## 3. Хранение
Данные хранятся в базе SQLite на сервере, где запущен Бот. Хранение не ограничено по сроку, пока функции активны. Удаление записей (мутов, варнов, аудита) выполняется командами модерации или удалением данных вместе с сервером.

## 4. Третьи стороны
- **Discord Inc.** — получение данных через Discord API; действует [Политика конфиденциальности Discord](https://discord.com/privacy).
- **YouTube / Twitch и другие платформы** — при поиске и трансляции музыки Бот обращается к ним через yt-dlp. Никакие пользовательские данные этим платформам не передаются.

## 5. Ваши права
Запросить удаление данных, связанных с вашим ID (варны, записи аудита), можно у администрации сервера или по контактам ниже. После удаления записи не восстанавливаются.

## 6. Дети
Бот не предназначен для лиц младше 13 лет (согласно Условиям Discord).

## 7. Изменения
Политика может обновляться. Продолжение использования Бота означает согласие с актуальной редакцией.
